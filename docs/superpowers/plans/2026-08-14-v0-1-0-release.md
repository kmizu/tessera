# Tessera v0.1.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** Publish Tessera's complete current MVP as its first GitHub Release, v0.1.0, with a Java 17 executable JAR and SHA-256 checksum.

**Architecture:** Keep release mechanics in small shell boundaries: one pure tag/version validator and one build-and-smoke script. Pin GitHub Actions by immutable commit SHA, run the same local artifact test in the tag workflow, and publish only from an annotated tag on a green merged main commit.

**Tech Stack:** Scala 3.4.2, sbt 1.10.7, sbt-assembly 2.4.1, Bash, Java 17, GitHub Actions, GitHub CLI.

## Global Constraints

- Release version is exactly 0.1.0; tag and title are v0.1.0 and Tessera v0.1.0.
- Runtime baseline is Java 17 or newer.
- Primary assets are tessera-0.1.0.jar and tessera-0.1.0.jar.sha256.
- The JAR manifest entry point is tessera.Main.
- Pull requests and pushes to main run the complete test suite on Java 17.
- Tag publication tests, assembles, smoke-tests, checksums, and verifies before publication.
- Tag/version mismatch prevents publication.
- Publication requires an annotated tag whose commit is in main and has a
  successful Java 17 CI check.
- Existing releases and assets are never silently replaced.
- The release tag is created on the merged, green main commit, never the feature branch.
- No Maven Central, native binaries, launchers, package-manager formulae, signing, SBOM, provenance, or new software license are included.
- Preserve all repository invariants in AGENTS.md.

#!/usr/bin/env bash
set -euo pipefail

repo_root="$(cd "$(dirname "${BASH_SOURCE[0]}")/../../.." && pwd -P)"
verifier="$repo_root/scripts/verify-release-tag.sh"

expect_success() {
  "$verifier" "$1" "$2"
}

expect_failure() {
  local expected="$1"
  shift
  local output
  if output=$("$verifier" "$@" 2>&1); then
    echo "expected failure for: $*" >&2
    exit 1
  fi
  if [[ "$output" != *"$expected"* ]]; then
    echo "expected diagnostic containing '$expected', got: $output" >&2
    exit 1
  fi
}

expect_success "v0.1.0" "0.1.0"
expect_success "v12.34.56" "12.34.56"
expect_failure "stable SemVer" "0.1.0" "0.1.0"
expect_failure "stable SemVer" "v0.1" "0.1.0"
expect_failure "stable SemVer" "v01.1.0" "01.1.0"
expect_failure "does not match" "v0.1.1" "0.1.0"
expect_failure "usage" "v0.1.0"

echo "release tag validation tests: OK"
~~~

- [ ] **Step 3: Implement the validator**

Create scripts/verify-release-tag.sh:

~~~bash
#!/usr/bin/env bash
set -euo pipefail

if [[ $# -ne 2 ]]; then
  echo "usage: verify-release-tag.sh <tag> <version>" >&2
  exit 64
fi

tag="$1"
version="$2"
stable_semver='^(0|[1-9][0-9]*)\.(0|[1-9][0-9]*)\.(0|[1-9][0-9]*)$'

if [[ ! "$version" =~ $stable_semver ]] || [[ "$tag" != v* ]] ||
   [[ ! "${tag#v}" =~ $stable_semver ]]; then
  echo "tag and version must use stable SemVer: tag=vX.Y.Z version=X.Y.Z" >&2
  exit 65
fi

expected="v$version"
if [[ "$tag" != "$expected" ]]; then
  echo "tag $tag does not match project version $version (expected $expected)" >&2
  exit 66
fi

echo "release tag verified: $tag"
~~~

- [ ] **Step 4: Implement the build-and-smoke boundary**

Create scripts/build-release.sh:

~~~bash
#!/usr/bin/env bash
set -euo pipefail

repo_root="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd -P)"
output_dir="${1:-$repo_root/dist}"
temporary_runtime=""

cleanup() {
  if [[ -n "$temporary_runtime" ]]; then
    rm -rf "$temporary_runtime"
  fi
}
trap cleanup EXIT

if [[ -z "${XDG_RUNTIME_DIR:-}" || ! -d "$XDG_RUNTIME_DIR" ||
      ! -w "$XDG_RUNTIME_DIR" ]]; then
  temporary_runtime="$(mktemp -d /tmp/tessera-runtime.XXXXXX)"
  export XDG_RUNTIME_DIR="$temporary_runtime"
fi

cd "$repo_root"
mkdir -p "$output_dir"

version="$(sbt --error 'print version' | tail -n 1)"
artifact_name="tessera-$version.jar"
artifact="$output_dir/$artifact_name"
checksum="$artifact.sha256"

rm -f "$artifact" "$checksum"
sbt test assembly

assembly_path="$(sbt --error 'print assembly / assemblyOutputPath' | tail -n 1)"
if [[ ! -f "$assembly_path" ]]; then
  echo "assembly output not found: $assembly_path" >&2
  exit 1
fi

smoke_output="$(java -jar "$assembly_path" check examples/Constants.tes)"
expected=$'id: OK\nalias: OK\ninferredAlias: OK'
if [[ "$smoke_output" != "$expected" ]]; then
  echo "release JAR smoke test failed" >&2
  printf '%s\n' "$smoke_output" >&2
  exit 1
fi

cp "$assembly_path" "$artifact"
(
  cd "$output_dir"
  sha256sum "$artifact_name" > "$artifact_name.sha256"
  sha256sum -c "$artifact_name.sha256"
)

printf '%s\n%s\n' "$artifact" "$checksum"
~~~

# Tessera v0.1.0

Tessera's first public release is an executable MVP of the language and its
synthesis-oriented kernel experiments.

## Highlights

- Minimal dependent-term kernel with normalization and definitional equality
- Declaration parser and CLI commands for checking, inspection, holes, and evaluation
- Structured eval --trace output across parser, core, kernel, and normalization
- synth do / for syntax with param, let, bind, and yield desugaring
- Tuple syntax for arities 2 through 10
- Explicit Scala Synth combinators whose generated terms are kernel-rechecked
- Ordered references to earlier accepted declarations in the same file
- Transparent delta reduction for accepted same-file constants

Install Java 17 or newer, download tessera-0.1.0.jar, and run:

~~~bash
java -jar tessera-0.1.0.jar check examples/Constants.tes
~~~

The example files are available in GitHub's source archive. Verify the download

## Current limits

This is an MVP rather than a stable language release. Imports, recursion,
opacity, general inductives, native binaries, and a source-compatibility
guarantee are not included yet.
